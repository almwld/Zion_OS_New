# skill-collision-detect

Detect name/description/trigger collisions before a new skill is created. Prevents duplicate skills in the registry by comparing the candidate against all existing SKILL.md frontmatter.

## When to Use

- Before creating a new skill
- Detecting duplicate skills in the registry
- Pre-creation collision check
