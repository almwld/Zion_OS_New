# evidence-triangulate

Triangulate a claim from 3+ independent sources. Cross-references evidence to establish confidence when no single source is authoritative.

## When to Use

- Verifying claims with conflicting sources
- Establishing confidence when no single source is authoritative
- Research requiring high epistemic rigor
