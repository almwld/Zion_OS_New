# alert-noise-reduce

Deduplicate and correlate alerts to reduce noise. Groups similar alerts by signature, suppresses flaps, and surfaces the signal through the noise.

## When to Use

- Alert fatigue is reducing response quality
- Multiple alerts fire for the same underlying issue
- Flapping alerts need suppression
