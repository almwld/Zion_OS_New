# org-mutation-precheck

Pre-check branch protection and signing requirements before bulk API mutations across repos. Classifies repos as API-safe, needs-signed-commit, or needs-PR.

## When to Use

- Before bulk API mutations across multiple repos
- Classifying repos by mutation safety
- Pre-flight for org-level operations
