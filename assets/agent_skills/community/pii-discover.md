Discover PII in datasets, logs, and code before processing. Scans for common PII patterns (SSN, email, phone, addresses) with confidence scoring.

## When to Use

- Before processing datasets of unknown PII content
- Scanning logs for accidental PII exposure
- Pre-publish PII discovery in code
